| [Changelog standards](changelog-standards.md) | How to write `CHANGELOG.md` entries and release notes that volunteers understand. |

| [Architecture](../ARCHITECTURE.md) | Diagrams of the presentation engine, remote control, media pipeline and synchronization. |
