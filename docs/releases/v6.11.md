## FRAMEDECKS v6.11

Plan the whole meeting on the FRAMEDECKS website. Download **FRAMEDECKS v6.11.exe** below and run it. It installs
over earlier versions and keeps all your data. A `.sha256` file is attached so you can check the download.

## What's New
- **The Meeting Form on the website** (framedecks.pages.dev → Meeting Form). It has the same sections as the Excel
  Meeting Form: meeting details, Frames, their Content, discussion questions and scripture readings. Add, change,
  move and delete Frames there; a linked PC shows them within about a minute, laid out as an Excel import would.
  Owners and admins edit; everyone else reads.
- **Open FRAMEDECKS from the website.** On a Windows PC, the website's Overview checks for the FRAMEDECKS camera and
  offers either the download or **Open FRAMEDECKS on this PC**. The installer registers that link for you.

## Enhancements
- The Excel Meeting Workbook (import, template, export and undo) is now in **Settings → Data / Backup**. The
  Meeting menu, the Meeting tab and the empty Studio no longer show it. The command palette's "Meeting from Excel"
  opens that Settings page.

## Fixes
- Nothing new to fix in this release.

## Performance Improvements
- Planning on the website sends only the Frames that changed; nothing is sent while you present.

## Known Issues
- Pictures, video, PowerPoint and audio files stay on the service PC. On the website, type the file name as it is
  in the PC's media folder; the PC's Diagnostics lists any name it cannot find.
- Scripture added on the website without its text shows the reference until the text is fetched on the PC.
- The Excel Meeting Workbook leaves the program in 6.12, once the website form has been tested in a real meeting.
- The installer is still not code-signed, so Windows SmartScreen may ask you to confirm: **More info → Run anyway**.
