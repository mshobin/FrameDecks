## FrameDecks v26.11.35

Three fixes from running 26.11.34. Download from **framedecks.com/download**, or let FrameDecks update itself. It
installs over every earlier version and keeps all your meetings, members, settings, notes, pinned Memory Cards and
recordings.

## What's New
None in this version.

## Enhancements
- **Go Live stays Go Live.** After Next and Next, the top bar's button still reads Go Live. A click goes live with the
  Frame you selected (it never re-takes the one already on air). To go off air, hold Go Live for a second.
- **Hide all is instant.** It takes everything off screen at once, with no Undo bar.

## Fixes
- **No season now always goes back to your own colours.** A season's colours could reach this PC through Sync without
  the note that a season was on, so the cards stayed on the season's green (without its snow) and No season did
  nothing. FrameDecks now recognises those colours as the season and No season clears them.

## Performance Improvements
None in this version.

## Known Issues
- The installer is not yet code-signed, so Windows SmartScreen may ask you to confirm: **More info → Run anyway**.
  Each release is checked with Microsoft Defender before it is published.
