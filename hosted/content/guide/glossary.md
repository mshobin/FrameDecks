# FrameDecks glossary

One word for each thing, the same in the program, on the website and in these guides. If a screen uses a different
word, the screen is wrong: fix the screen, not this list. (Owner-approved simplification, 27 October 2026.)

| Say | Means | Don't say |
| --- | --- | --- |
| **FrameDecks** | The program on the service PC, and the website that goes with it. Always written FrameDecks (capital F and D only). | FRAMEDECKS, Framedecks, KingdomConnect, the app, the software |
| **FrameDecks vCam** | FrameDecks's own camera: what you choose as the camera in Zoom or Teams. | the virtual camera, vcam, FrameDecks camera, FrameRelay (its name before 9.1) |
| **Frame** | One step of the meeting: what is on screen at one moment. | scene, slide, page |
| **Content** | What is on a Frame: a verse, a question, a picture, a video, text, a countdown. | layer, element, overlay |
| **Running order** | The Frames in the order they go on screen. | services list, scene list, playlist |
| **Plan** | The website page where you plan a meeting (Frames, questions, scripture, the presenter's script) and see its history. It replaced the Meeting Form and Running order pages. | Meeting Form (the Excel file is the *Meeting Workbook*), services |
| **Home** | The website's first page: your next service and whether it is ready. | Overview, dashboard |
| **Studio** | The one place where you plan, edit and run a meeting. Previous, Next, Go Live, Hide all and Live tools are always in its top bar. (The separate Prepare / Run views were removed in 8.0.) | edit mode, design view, show mode, live mode, presenter mode |
| **Decks** | The section under the Frames list that holds the selected Frame's Content (**+ Deck** adds to it). | layers |
| **Go Live** | Put the chosen Frame on screen. | take, cut, send |
| **Previous / Next** | Put the Frame before or after the one on screen. | back / forward, prev |
| **Up next** | The Frame that Next (or Go Live) puts on screen, marked **NEXT** in the Frames list. | cue, preview (alone) |
| **On screen** / **Live** | What the audience sees now. | on air (except the **Off air** status), program |
| **Hide all** | Clear the screen (Esc). | clear all, HIDE ALL |
| **Black screen** | Make the picture black (K). | blackout (the LAN phone remote's Advanced view still says *Blackout*) |
| **Freeze the picture** | Hold the picture while you fix something (F). | pause |
| **Draw on the picture** | Draw on the live picture (D). | annotate (the shortcut list still says *Annotate*) |
| **Emergency screen** | A message for everyone when something goes wrong. | slate, panic screen |
| **Teleprompter** | Your script, which only you see: one window that stays on top of Zoom or Teams and is hidden from screen sharing and recordings (R). | speaker view, confidence monitor, prompter overlay |
| **How people see it** | The way your meeting reaches people: FrameDecks vCam in Zoom or Teams, the **Share Window**, or a projector, TV or OBS. | output, display settings, sources |
| **Share Window** | A clean window with only your Frames, to share in Zoom. | presentation window, present mode |
| **Live tools** | The menu with Black screen, Freeze, Draw, the Teleprompter and the Emergency screen. | Program menu |
| **People** | Everyone in your member list (Members → People): the list, or the table. | directory, manage, contacts |
| **Team** | Your organisation, church, class or group on the website: its people, its plans and its service PCs (*workspace* in the code). | church (on the website), workspace, organisation, tenant |
| **Service PC** | The Windows PC that runs the service, linked to your team (*Linked PC* in the program). | computer, device, runtime, client |
| **Your workspace** | Your name, your teams, invitations and Trusted Devices (the avatar at the top). | account, profile, workspace admin |
| **Trusted Device** | A browser you chose to trust after the emailed link: it opens your workspace with no new link for 180 days (Manage Devices). | remembered device, saved sign-in |
| **Phone remote** | The page on a phone, on the same Wi-Fi, that runs the service (Settings → Phone & iPad Remote). | LAN remote, iPad app |
| **Live page** | The website page that runs a service from anywhere. | cloud remote, companion remote |

Words that stay inside the code (never on a screen): scene, layer, vcam, take, overlay page (say *overlay link* for OBS).
