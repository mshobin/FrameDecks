## FrameDecks v26.11.23

A summary of every meeting, and a prayer wall people can write to from their phones. Download from
**framedecks.com/download**, or let FrameDecks update itself. It installs over every earlier version and keeps all your
meetings, members, settings, notes, pinned Memory Cards and recordings.

## What's New
- **Meeting summary.** When a meeting ends, the Studio offers its summary: how long it ran, each Frame and how long it
  was on (against the planned minutes), every question asked and scripture read, in order, and how many Memory Cards
  and prayer requests there were. **Print / Save as PDF**, **Copy** or **Email** it. Past meetings are kept on this PC
  (Settings → General → Meeting summary, or search "summary" in the palette).
- **Prayer requests wall.** Studio → Engage → **Prayer requests** → Open the prayer wall. People scan the QR (or go to
  framedecks.com/pray and type the 6-letter code) and send a request from their phone, with no account. **Show the
  code on screen** puts it on the picture for people on Zoom or Teams. Requests come only to you: nothing is shown
  until you choose **Show** (anonymously) or **Show with the name** they gave; **We're praying for…** gathers the ones
  shown on one card, without names. On screen they are Memory Cards.

## Enhancements
- **Private by design.** A request is deleted from the cloud the moment this PC takes it in (and after 24 hours in any
  case); on this PC it is kept only in memory and forgotten when you close the wall. One network can send 5 requests in
  10 minutes; wrong codes are limited like join codes.
- **Smart Next starts again** from what a Frame shows when it is taken again.

## Fixes
- Smart Next could skip straight to the next Frame after a Frame was taken a second time.

## Performance Improvements
None in this version.

## Known Issues
- The prayer wall needs this PC connected to your FrameDecks workspace (Settings → Sync).
- The installer is not yet code-signed, so Windows SmartScreen may ask you to confirm: **More info → Run anyway**.
  Each release is checked with Microsoft Defender before it is published.
