## FrameDecks v26.11.6

The Command Center with nothing around it, on every PC. Download from **framedecks.com/download**, or let FrameDecks
update itself. It installs over every earlier version and keeps all your meetings, members, settings, notes, pinned
Memory Cards and recordings.

## What's New
None in this version.

## Enhancements
- Clicking just outside the Command Center now reaches the window behind it straight away.

## Fixes
- **No more grey box around the Command Center.** On some PCs Windows drew the Command Center's whole window as a
  grey rectangle behind the bar and its chips, over the Studio and the desktop. The window now takes exactly the
  shape of what it shows (the bar, the chips, the open panel and Keep open), changing shape as panels open and close,
  so there is nothing left for Windows to paint.

## Performance Improvements
None in this version.

## Known Issues
- The installer is not yet code-signed, so Windows SmartScreen may ask you to confirm: **More info → Run anyway**.
  Each release is checked with Microsoft Defender before it is published.
